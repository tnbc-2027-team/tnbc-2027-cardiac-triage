# Mechanical

Enclosure, cuff/strap and finger-clip CAD.

- Commit your CAD files here like any other file. GitHub rejects any single file over 100 MB, so if an assembly is bigger, save a lighter copy (for example a STEP export) instead.
- If you work in cloud CAD (Onshape, Fusion), export a STEP file here whenever the design changes in a way Electrical needs to know about.
- Agree board size, mounting holes, connector and display positions with Electrical before either side finalises.
- Needed for the design report: a full assembly model and an exploded view with a parts list.
