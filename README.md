# tnbc-2027-cardiac-triage

**New here?** Follow [docs/github-guide.md](docs/github-guide.md) to get set up. It takes about 10 minutes, no Git experience needed.

## Rules

1. Work on your own branch, never directly on `main`.
2. When your change is ready, open a pull request and ask one teammate to review it.
3. Write clear commit messages, like "Add SpO2 sensor to schematic", not "update".
4. Electrical: everyone uses **KiCad 10**.
5. Stuck? Ask your subteam lead. Nothing in Git is lost for good.
